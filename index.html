Questions fréquentes

Faut-il payer pour utiliser le site ?

Non, la consultation et la création de boutique sont gratuites pour les vendeurs comme pour les acheteurs.

Comment passer une commande ?

Ouvrez une publication, cliquez sur « Je suis intéressé », remplissez le formulaire puis envoyez la commande : WhatsApp s'ouvre avec votre message déjà prêt pour le vendeur.

Le paiement se fait-il sur le site ?

Non. Le paiement et la livraison se règlent directement avec le vendeur, selon les modalités convenues avec lui.

Combien de photos puis-je publier ?

Jusqu'à 10 photos par publication, choisies directement dans votre galerie.

Puis-je modifier ma boutique ?

Oui. Depuis « Mon espace », vous pouvez changer votre nom, votre description et votre photo de profil.
